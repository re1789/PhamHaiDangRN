1. Cần để có thể chạy trên web
npx expo install react-dom react-native-web

2. Expo router: 
npx expo install expo-router react-native-safe-area-context react-native-screens expo-linking expo-constants expo-status-bar

3. Các thư viện Icon:
Link thư viện: https://oblador.github.io/react-native-vector-icons/
npm install @react-native-vector-icons/ionicons
npx expo install @react-native-vector-icons/material-icons
npx expo install @react-native-vector-icons/ionicons
npx expo install @react-native-vector-icons/fontawesome-free-solid

4. Nếu không chạy được, mở powershell rồi nhập lệnh, chạy rồi bấm a rồi enter:
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

5. Những gói cài đặt expo:
- npx create-expo-app TênProject --template blank
- npx expo install react-native-safe-area-context
- npm install

6. Khác:
- npx expo install react-native-element-dropdown
- Tích hợp expo router vào dự án:
|- Cập nhật file package.json: đổi giá trị của main thành expo-router/entry
|- Tạo thư mục app(có thể xoá folder App) gồm các file làm màn hình chính: index.js, _layout.js(file điều hướng)
|- Tạo một folder khác làm màn hình kế(ví dụ như products): index.js, [id].js(một id động)
